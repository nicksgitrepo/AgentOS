The archived task chats are no longer active workflow inputs. Their public
handoff records remain in this authoritative worktree; their temporary
worktrees are not treated as an additional source of truth. The Controller
must still produce the independent audit and integration receipts before this
platform batch can be accepted. No private paths, credentials, provider
identities, or raw chat links belong in these records.

The current independent static audit is retained at
`docs/platform-foundation-independent-audit.md`. It confirms the exact twelve
handoff set and records the remaining clean-source, clearance, and host/test
conditions; it does not release feature lanes or convert any historical
archive into a compliant closeout.

The first preservation pass exposed a lifecycle defect: the platform tasks were
archived after their handoff records were preserved, but before a per-task
audited integration receipt was recorded. The general governance repair now
requires integration before archive. This index deliberately records that
historical state as pending reconciliation rather than claiming a completed
platform merge.
