# Specialist Gate Library intake boundary

The Specialist Gate Library is an external, isolated release train. AgentOS does not package, admit, merge, activate, or infer readiness from a partial library worktree.

Until a final typed packet is received, AgentOS reports `SPECIALIST_GATE_LIBRARY_EXTERNAL_CUSTODY` and `NOT_RECEIVED`. The legacy local block payload is excluded from the AgentOS 3 bundle. Its historical review remains only as explicitly labeled legacy provenance; it does not satisfy the current intake contract or grant intake authority.

A packet must bind an exact remote commit/tree, content-addressed manifest and roster, truthful address/compileable/planned/not-applicable counts, dependency closure, focused proof, independent clearance, migration and invalidation artifacts, and an all-false authority surface. Packet validation still returns `PACKET_VERIFIED_PENDING_INDEPENDENT_AGENTOS_ADMISSION`; validation never self-admits or merges the library.

Any packet, manifest, roster, proof, migration, invalidation, source, or truth-count change invalidates downstream role-context manifests and requires fresh AgentOS admission. Rollback removes the candidate from intake custody and restores `NOT_RECEIVED`; it never mutates the external source train.
