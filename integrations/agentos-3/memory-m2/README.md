# Memory M2 typed test adapter

This directory is an immutable, selectively packaged input for the inactive
AgentOS 3.0 test build. Its runtime is local-first and private-custody only.
The adapter never enables itself, replaces existing custody, migrates a
project, activates a provider, or publishes a bundle. The supplied source,
proof, and park identities are recorded in the integration contract; this
package contains no private control receipts or absolute source paths.
