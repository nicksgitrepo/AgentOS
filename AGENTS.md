# AgentOS repository instructions

This repository owns portable AgentOS governance only.

- Keep all normative payloads project-agnostic.
- Treat product context as data supplied through typed project configuration or authority-corpus templates.
- Never copy product names, private paths, credentials, provider accounts, task identities, deployment identities, or domain-specific policies into the portable kernel.
- Preserve deterministic behavior, low-chat autonomy, exact handoffs, true-blocker escalation, and hostile-test coverage.
- Keep `2.1rc` prepared but inactive until an explicit activation decision is recorded.
- Make changes through isolated branches or worktrees, with focused tests and an exact handoff.
